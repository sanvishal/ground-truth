# GROUNDTRUTH

## Product

A desktop-only, two-level cooperative point-and-click game for a human player and a live browser agent. The human plays Demi through a fixed ship scene; the agent plays KORE through WebMCP tools. Each is the other's only instrument: Demi can see but cannot read KORE's telemetry, while KORE can read instruments but cannot see the room.

## Audience and moment

Built for one memorable hackathon playthrough in a Codex or WebMCP-enabled browser. The interface teaches the player how to connect the agent, then gets out of the way of the room, dialogue, and physical decisions.

## Voice

Restrained, intimate, tired, and technically credible. Demi is competent and slightly expressive; KORE is plain-spoken, source-blind, and honest about uncertainty. Their bond is mechanical trust, not romance, grief companionship, or conventional professionalism.

## Visual direction

Crisp pixel art, dark industrial ship interiors, quiet surfaces, selective warm work lights, and restrained amber UI. The room is always the dominant visual. UI should feel composable and ship-adjacent without becoming a dashboard.

## Interaction principles

- Fixed room, point-and-click interaction; no walking avatar.
- Dialogue uses short paged type-on with clear manual continuation.
- ImpactfulBits is the UI font; PixelSans is the dialogue font.
- Demi's hands are free; KORE's reserve is scarce and visible.
- Developer tools must remain outside the game canvas.
- Stalling is free but unproductive; agent latency never harms game state.

## Anti-references

Avoid app-like top bars, telemetry walls, mascot-AI expressiveness, glossy sci-fi HUDs, visual clutter, melodrama, and any UI that obscures changes in the room.
